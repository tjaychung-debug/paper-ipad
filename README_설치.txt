Paper — iPad용 PDF 전체화면 뷰어

사용 기능
- 내가 가진 PDF를 직접 등록. 등록한 PDF 여러 개를 목록에서 전환/삭제
- 이전에 열었던 PDF를 다음 실행 때 다시 표시 (IndexedDB 기반)
- 세로 스크롤만 허용. 좌우 스와이프로 페이지 넘김/툴바 표시 불가
- 두 손가락 벌리기/오므리기로 PDF 확대·축소 (1.0~3.2배)
- PDF 화면 한 번 탭: 아무 UI도 나타나지 않음
- 같은 위치 두 번 탭: 도구 막대 표시/숨김
- 숨김 모드에서는 페이지 번호/버튼/상하 바 모두 없음. PDF 페이지가 화면 가로 폭에 맞춰 끝에서 끝까지 표시됨
- PDF를 원본 그대로 iPad 파일 앱에 공유 또는 다운로드
- PDF 내용은 PDF.js로 기기 내에서 처리되며 앱 서버에 업로드하지 않음

중요: iPad에서 Safari 메뉴를 없애는 설치 방법
1. 이 폴더의 index.html, app.js, manifest.json, sw.js, icon-192.png, icon-512.png를 모두 GitHub 리포지토리 최상위 폴더에 올립니다.
2. GitHub 리포지토리 -> Settings -> Pages -> Build and deployment: Deploy from a branch -> Branch: main / (root) -> Save.
3. 게시된 HTTPS 사이트(예: https://YOURID.github.io/YOUR_REPO/)를 iPad의 Safari로 엽니다.
4. Safari 공유 버튼 -> '홈 화면에 추가' -> '추가'.
5. 홈 화면에 생긴 'Paper' 아이콘으로 실행하세요. (Safari 탭에서 여는 것과 다름)
6. 첫 실행은 인터넷 연결이 필요합니다. PDF.js 렌더러가 CDN에서 로드되고 가능한 경우 캐시됩니다.
7. 'PDF 불러오기' -> 파일 앱에서 PDF 선택. 문서가 열리면 도구 막대는 자동으로 사라집니다.

일반 HTML 테스트
- Paper_단일파일_시험용.html 은 파일 하나로 코드를 합친 편의 버전입니다.
- iPad Files의 미리보기(Quick Look)에서는 웹앱처럼 실행되지 않을 수 있으므로 HTTPS에서 열어야 합니다.
- 단일 HTML 파일을 Safari 탭에서 열면 Safari 자체 주소창/탭 바는 제거할 수 없습니다.
- Safari 시스템 UI가 완전히 사라지는 형태는 홈 화면 웹앱이 더 적합합니다.

주의/제약
- iPadOS의 시스템 상태 표시줄/홈 인디케이터까지 강제로 숨기는 것은 웹 기술로 보장할 수 없습니다. 그 수준의 완전한 몰입형 화면에는 네이티브 iPad 앱이 필요합니다.
- 웹앱 최초 실행 시 PDF.js 스크립트를 CDN에서 받아야 합니다. 이후 캐시가 되어도 iPadOS 저장소 회수나 업데이트에 따라 인터넷이 다시 필요할 수 있습니다.
- 등록된 PDF는 서버가 아니라 기기 내 IndexedDB에 저장됩니다. iPad 저장 공간 부족, 웹사이트 데이터 삭제, 개인정보 보호 설정, 기기 교체 시 보관된 문서가 사라질 수 있습니다. 중요한 PDF는 별도 보관하십시오.
- 큰 PDF(수백 페이지)의 확대 렌더링은 iPad 메모리 한도의 영향을 받을 수 있습니다.
- 이곳에서는 iPad Safari 하드웨어 동작 테스트를 할 수 없었으므로 실제 기기에서 확인이 필요합니다.
